# Privacy Policy

**Effective Date:** September 2026

Holfuy Upgrader is designed to update the firmware of Holfuy weather stations over a direct USB connection.

## Information Collection

Holfuy Upgrader does **not** collect, store, transmit, or share any personal information.

The application does not:

* require user accounts or sign-in
* collect personal information
* collect location information
* collect device identifiers
* collect analytics or usage statistics
* display advertising
* use advertising identifiers
* transmit personal information to the developer, Holfuy, or any third party

## Firmware Downloads

Holfuy Upgrader can automatically obtain information about available firmware and download firmware files from Holfuy over the Internet.

Downloaded firmware files are maintained in a local firmware repository on the Android device. The application does not transmit personal information to Holfuy as part of this process.

Firmware files stored in the local repository are transferred to a connected Holfuy weather station over the USB connection when the user initiates a firmware update.

## USB Communication

The application communicates directly with compatible Holfuy weather stations using a USB connection to perform firmware updates.

Communication with the connected weather station occurs locally between the Android device and the station.

Firmware files selected by the user are transferred from the Android device directly to the weather station over USB.

## Diagnostic Information

Holfuy Upgrader can generate a diagnostic report at the user's request.

The report contains technical information intended to help diagnose application and firmware-update problems. It is designed not to contain personal information, location information, device identifiers, credentials, or other private information.

The diagnostic report is generated locally on the Android device. It is not automatically transmitted to the developer, Holfuy, or any third party.

When the user taps **Send Diagnostics**, Android's standard sharing facility is used to allow the user to select an application or recipient with which to share the diagnostic report. The user controls whether the report is shared and selects its destination.

## Third-Party Services

Holfuy Upgrader does not use third-party analytics, advertising, or tracking services.

The application uses Android's standard sharing facility when the user explicitly chooses to send a diagnostic report.

## Google Play

The application is distributed through Google Play. Google may collect information as described in Google's own privacy policies and terms of service. This Privacy Policy applies only to Holfuy Upgrader.

## Changes to This Privacy Policy

If this Privacy Policy changes, the updated version will be published in this repository and, where applicable, made available through Google Play.
